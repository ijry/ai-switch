# 统计页分组统计的列表 / 图表切换

日期：2026-09-03
状态：已实现

## 背景

统计页的「分组统计」只有表格一种形态，能回答「这段时间里哪个模型花得最多」，但回答不了「花在哪几天」。用户要求在分组统计右侧加列表 / 图表切换，图表为按时间堆叠的 Token 柱状图，并与上方时间区间联动；同时区间预设要补 24h / 7d / 30d，按钮改小以省空间。

## 时间区间

`periods` 从 4 个扩到 7 个，按「日历区间 + 对应滚动区间」成对排列：当日 · 24h · 本周 · 7d · 本月 · 30d · 累计。

- 日历区间（当日 / 本周 / 本月）取本地零点，与原行为一致。
- 滚动区间（24h / 7d / 30d）从**当前时刻**回退，不对齐零点——「最近 24 小时」若对齐零点就不再是 24 小时。
- `since` 改为在 `queryFn` 内计算，`queryKey` 只带 `period`。原先 `useMemo` 把 `since` 冻结在点击那一刻，窗口会随挂载时间变长（开着 10 小时的「24h」实际是 34 小时）；现在每次轮询都重算，缓存键仍稳定不闪烁。

区间按钮与分组维度按钮统一缩到 `px-2 py-1 text-[11px]`，容器从 `grid-cols-4` 改 `grid-cols-7`。

## 后端：`series`

`UsageOverview` 新增 `series: UsageTrendSeries`，与 `groups` 同一批合并后的行算出，因此柱子之和等于上方汇总卡（除无时间戳的行，单独报数）。

- **桶宽自选**：按窗口跨度在 hour / day / week / month 里挑最细且桶数 ≤ 48 的一档。当日→小时，7d/30d→天，累计跨季→周、跨年→月。前端标题跟着 `unit` 走（「按天 / 按小时 Token 趋势」），不写死。
- **桶边界用本地零点**：`TrendFrame.offset` 由调用方传 `Local::now().offset().fix()`，不假定 UTC——否则东八区 23:00 的请求会被算进前一天，和用户选的「当日」对不上。测试固定 `+08:00`，不读机器时区。
- **空桶保留**：没有请求的那天也占一根位置，否则轴会谎报剩下柱子的间隔。
- **四个维度一次算完**，和 `groups` 一样，切维度不触发重新请求。
- **系列上限 8 + 其他**：超出的尾部折进 `其他`。这不是随手定的数——配色只有 8 个通过色觉校验的槽位。
- **柱高只含输入+输出 Token**：真实语料里缓存读取比输入高一个数量级，算进去就画成了一张「缓存图」；缓存数字放在 tooltip 里。

`assemble_overview` 多收一个 `TrendFrame`；`core/usage_overview.rs` 与 web 分发层无需改动，序列化后两个端一起拿到新字段。

## 前端：`UsageTrendChart`

手写 SVG，不引图表库（沿用 `2026-09-02-usage-overview-merge-design.md` 的非目标）。

- 8 色分类色板经色觉校验：白底相邻对 CVD ΔE 最差 9.1（目标 ≥8）、常视觉最差 19.6（下限 15）。其中 3 色对白底对比度低于 3:1，靠「同一份数字的列表视图一键可达」满足救济要求。
- **颜色按实体哈希分配**，不按排名：切区间后排序会变，但读者刚学会「某模型是蓝色」不该被重新上色。哈希撞槽时线性探测，可见系列之间不会同色。`其他` 固定中性灰。
- 堆叠段之间留 2px 表面间隙而不描边；柱顶 4px 圆角、基线端方角；网格线实线发丝级。
- **柱顶数值按能否放下决定**：带宽 ≥34px 时每根都标，否则只标峰值——30 根柱子各标一个数会互相压字。X 轴标签同理按带宽抽稀。
- 每根柱一个透明命中区，带 `aria-label`（含精确 Token 数）且可聚焦，hover / focus 弹同一份 tooltip：桶标题、总 Token、请求数、费用、缓存，以及各系列明细。
- 切区间加载中时整张图降到 60% 透明度保留上一帧，不闪骨架屏。

切换按钮只在已展开某个维度时出现——没有维度可画时，切换只是在两个空框之间来回。

## 测试

- Rust：桶宽选择（时/天/周/月）、空桶保留、本地零点边界、柱和等于汇总、尾部折叠、第 9 个系列折叠、无时间戳计数、累计从最早行起算。
- 前端：切换按钮的出现条件与 `aria-pressed`、图表标题跟随 `unit`、7d 滚动窗口的 `since`、无时间戳提示；`UsageTrendChart` 几何测试（标签放不下时只标峰值、X 轴抽稀、所有色块落在绘图盒内、柱宽上限、空数据文案）；`assignSeriesColors` 的稳定性与唯一性。
